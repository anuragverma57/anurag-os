# Anurag OS

A personal developer operating system to manage my learning, track progress, and showcase my journey.

## 🚀 Overview

Anurag OS is my all-in-one platform where I:

- Track my DSA, System Design, and Backend preparation
- Maintain structured notes and cheat sheets
- Manage daily tasks and learning goals
- Document interview experiences
- Showcase selected work as a public portfolio

## 🧠 Purpose

Instead of using multiple tools, I’m building a single system that helps me:

- Stay consistent
- Track real progress
- Reflect and improve
- Present my journey in a structured way

## 🔒 Structure

The project is divided into two parts:

- **Public Layer**
  - Portfolio
  - Projects
  - Selected notes
  - Interview experiences

- **Private Layer**
  - Personal dashboard
  - Full progress tracking
  - Notes and todo manager
  - Learning analytics

## 📈 Vision

To build a system that evolves with my journey — from preparation to professional growth — and serves as both a tool and a reflection of my work.

Currently in development.
