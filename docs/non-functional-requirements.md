# Non-Functional Requirements

## Performance

- Fast page load (< 2s)
- Optimized rendering for public pages

## Security

- Admin-only write access
- No public data modification
- Secure authentication

## Scalability

- Should support adding backend and AI features later

## Usability

- Simple and intuitive UI
- Minimal clicks for admin actions

## Maintainability

- Clean code structure
- Modular components

## Reliability

- Data persistence (no data loss)
